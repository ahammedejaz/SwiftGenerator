# Synthetic MT541 to sese.023 mapping fixture

This file is test evidence for the conversion engine. It is not SWIFT guidance, an ISO
20022 mapping specification, a market-practice document, or an approved client mapping.
It uses the repository's existing synthetic MT541 and sese.023 sample values to exercise
direct, transformed, conditional, one-to-many, derived, and not-represented outcomes.

The fixture is never production eligible. A reviewed Mapping Pack based on authorized
mapping evidence must replace it before real business conversion is offered.
